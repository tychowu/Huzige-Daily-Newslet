# 发布前检查清单

逐项打勾。**清单不过不导出。**

先跑机器体检，`[B]` 有任一条就不往下走：

```bash
node ~/.workbuddy/skills/global-finance-newslet/scripts/audit_layout.cjs cards/
```
它查的是目测最容易漏的九项：遮挡、留白（视觉件内部填充率）、省略号吃字、**行内重叠**（`grid-auto-rows:1fr` 压扁导致数值行压在名称行上）、裁剪截断、小字（<22px）、对比度（WCAG AA）、信息重复（文字区重报视觉件数字）、**溢出**（视觉件内容顶出容器）。

> 「行内重叠」这一项是 2026-10-21 补的。之前十项指标网格叠字时，
> 每一行文字自己都没超出父容器，所以「截断」抓不到，只有专门查
> `.gc / .mx-row / .ms-node / .rs-row / .mb-row` 的 `scrollHeight` 才抓得住。

## 通用清单

- [ ] 1. 期号与日期正确，无「样刊／样本」字样
- [ ] 2. 主题句是判断句，不是「市场综述」
- [ ] 3. 同一张卡里几条讯息互不重复，各回答不同问题

## 四张卡专项

**结构**

- [ ] 4 张齐全，编号 01–04 与 `section` 顺序一致（三条 → 温度 → 三件事 → 保险）
- [ ] 每张 2–3 条讯息，`items[]` 顺序 = 阅读顺序
- [ ] 每条都有 `kicker` / `tag` / `title` / `desc` / `visual`
- [ ] `corner` 字段填了，**只写段落名**（今日三条 / 隔夜市场温度 / 今日三件事 / 保险与税务观察），
      **不加「· 机制」「· 一览」这类后缀** —— 多张卡后缀相同时读者会以为是同一条内容
- [ ] 每条 item 都有 `points[]`（1–3 个短点），`build_cards.py` 没有报「要点渲染 N/M 条」

**占屏比例（每期都要重新确认）**

- [ ] **`build_cards.py` 没有打高度告警**：没有「分到 Npx 但自然上限只有 Mpx」，没有「条目高度落差 N×」
- [ ] **一条讯息占多高由内容量决定，不是手填权重**（`data.json` 里不该再有 `w` 字段）
- [ ] **条目区从主标题下方一直铺到口径注上方，中间没有空带**。
      目视法：条目底边应紧贴 note 顶边；差 100px 以上就是分配没生效
- [ ] 02 号这类含宽表的卡**只放两条**；十条以上数据的宽表再加窄件就会叠字
- [ ] 高密度条目（网格／多节点流程／多行条形）没有被压到叠字
- [ ] 低密度条目（大数字 + 少量附属）没有独占半张卡
- [ ] **左侧文字列顶部对齐**，没有被拉高的条目里文字垂到中间
- [ ] **左栏文字需求进了预算模型**（`max(左栏, 右栏)`，不是只算右栏）——
      漏掉左栏时第三条要点会被裁掉，体检报「溢出 div.it-l 里的 div.pt」
- [ ] **条目高度总和 = 条目区高度**，没有溢出（`items.scrollHeight == items.clientHeight`）

**文案**

- [ ] **每条 `desc` ≤ 18 字且单行**；`build_cards.py` 没有打 `⚠️ 解释 N 字 > 18`
      （desc 占 2 行就是 84px，是左栏最大开销；压到 1 行省下的空间正好放要点）
- [ ] **每条 `title` 单行**（约 13.8 em 以内）
- [ ] **每条要点单行**（约 19 em 以内）；预检报「要点放不下」就把它拆短
- [ ] **解释句不重报视觉件里的数字**（`audit_layout.cjs` 第 7 项会报 `[W] 信息重复`）
- [ ] **视觉件里没有来源／时点**（`USDCNH 纽约尾盘`、`CME FedWatch · 10/20`、`截至 xx` 这类）——
      来源统一放 footer，预检会拦
- [ ] **视觉件里的说明 ≤ 16 字**，且只写读图口径（`中轴为 0`、`两者几乎一样高 = 曲线更平`）
- [ ] **结论条不重报任何条目里的数字**
- [ ] **主标题全部单行**，没有一张折行（`render.cjs` 会报「主标题折行」）
- [ ] 语义标签只用四档定稿色：**窗口绿 `#266C4B`／高位蓝 `#1F497D`／风险红 `#800000`／观察黄 `#8B5B10`**，

- [ ] 没有按"对比度必须齐平"去压平四档明暗 —— 红最重、绿黄偏轻是**刻意的层次**，不是缺陷

- [ ] 眉标行的「分类标题」（监管／行业／税务等）**没有**被当成标签上色 —— 它是标题层级

## 数字核验三件套

每个出现的数字都要能回答：

1. **来源** —— 哪家机构／哪个行情库／哪条公告
2. **截止日** —— 具体到哪一天收盘／哪个统计截止日
3. **口径** —— 离岸还是在岸、现货还是期货、年化还是新单

答不上来任何一个 → 删掉这个数字，不要用模糊表述糊过去。

## 事实 / 测算 / 预测 措辞

| 类型 | 措辞要求 | 反例 |
|---|---|---|
| 事实 | 直接陈述 + 截止日 | — |
